# Changelog

## 1.0.1

- Face packs: drop `.json` files in the `packs` folder (`FACES_PACKS_DIR`, `/data/packs` in Docker) and reload; the old `?pack=<url>` option is removed.
- Renamed to Funny Faces (the stored settings keep their old keys so nothing is lost).
- Mouth shapes: nine Rhubarb-style shapes chosen live from the spectrum in the browser.
- Songs: an audio file or `?audio=` link is analysed once in the browser into a small mouth track; optional
  centre-channel "Singer focus".
- Wider mouth range in the built-in faces so shapes read clearly.
- Relay format unchanged.
