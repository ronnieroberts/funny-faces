Funny Faces: your own faces go in this folder.

1. Copy one or more face pack files (each one is a single .json file) into this folder.
2. Reload the Funny Faces page in your browser (no need to restart).
3. Open the Faces tab. Your packs are listed after the built-in faces, marked
   "from the packs folder".

If a file cannot be used, the Faces tab says which file and why.
Up to 20 files, 2 MB each. To remove a pack, delete its file and reload.

How to make a pack: see docs/FACEPACK.md in the project, or
https://github.com/ronnieroberts/funny-faces/blob/develop/docs/FACEPACK.md
